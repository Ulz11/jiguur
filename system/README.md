# Жигүүр Зам ХХК — Удирдлагын систем

> **Дизайн:** Жигүүр Зам брэндийн navy + улбар шар (лого, brand pattern-ууд),
> IBM Plex Sans/Mono + Manrope. Redesign нэгтгэгдэж production-д бэлэн болсон.

Хэв хашмал, тулаас, трубаны **түрээс + худалдаа**, тооцоо, санхүүг нэг дор хөтөлдөг
систем. Messenger чат, гар падан, Numbers файлын оронд.

**Хувилбар 1.0.0** · 64 автомат тесттэй · бодит дата шилжсэн

## 1. Ажиллуулах (өдөр бүр)

```
system\run.bat   ← давхар дарна
```

Цонхонд гарч ирэх хаягуудыг ашиглана:

| Хаана | Хаяг |
|-------|------|
| Сервер асаасан компьютер дээр | `http://localhost:8000` |
| Бусад компьютер, утас, таблет (нэг WiFi) | `http://192.168.x.x:8000` — run.bat цонхонд бичигдэнэ |

> Үйлдвэрийн дарга таблетаасаа, санхүүч өөрийн компьютерээсээ орохын тулд
> **сервер асаасан компьютер асаалттай** байх ёстой. Сүлжээний хаяг өөрчлөгдвөл
> run.bat дахин ажиллуулж шинэ хаягийг харна.

Шаардлага: **Python 3.11+** ([python.org](https://python.org) — суулгахдаа
«Add Python to PATH» гэдгийг заавал чагтална).

## 2. Юу хийж чадах вэ

**Шинэ (v1.1):** Авлага цуглуулах ажлын урсгал (хэнд залгах, хэн юу амласан) ·
Аналитик (материалын өгөөж + 90 хоногийн мөнгөний прогноз) · Утсаар тооллого хийх горим ·
Бартерын зогсонги хугацааны хяналт · Барьцааны тооцоо (буцаах/суутгах) ·
Гэрээний бүрэн PDF · Үйлдлийн бүртгэл (audit log)


**Гэрээ (системийн зүрх)** — түрээс/худалдаа, материал бүрт өөр тариф, 30 хоногийн
цикл гэрээний өдрөөс. Ачилтыг дарга баталгаажуулмагц нөөц хөдөлж тооцоо эхэлнэ.
Буцаалт хоногоор пропорц бодогдоно, зэрэглэл шилжинэ (А→В), засварын фикс болон
актын НБҮнэ автоматаар нэхэмжлэлд орно.

**Тооцооны мөчлөг — 30 хоног эсвэл КАЛЕНДАРЬ САР.** Шинэ гэрээний 3-р алхамд
сонгоно, дараа нь гэрээн дотроос («Мөчлөг:» дээр дарж) солино.

| | 30 хоног *(анхны)* | Календарь сар |
|---|---|---|
| Цикл | эхлэх огнооноос яг 30 хоног (`3.15–4.14`) | эхлэх огнооны ӨДӨР бүрд (`4.01–5.01`, `5.01–6.01`) |
| Хоног | үргэлж 30 | тухайн сарын жинхэнэ урт (28–31) |
| Дүн | цикл бүр адил | **31 хоногтой сар ×31/30 илүү** нэхэгдэнэ |

Зангилаа нь эхлэх огнооны өдөр: 14-нд эхэлсэн гэрээ сар бүрийн 14-нд шинэ цикл
эхлүүлнэ. Тэр өдөр богино сард байхгүй бол (29–31) **сарын сүүлчийн өдөр** болж
хумигдаад, дараагийн сард **зангилаандаа эргэж очно**:
`1.31 → 2.28 → 3.31 → 4.30 → 5.31` (өндөр жилд `2.29`).

Нэхэмжлэлтэй гэрээний мөчлөг солиход эхлэх огноо солихтой ижилхэн — **цикл
бүрийн хуучин→шинэ дүнг** харуулсан цонх гарч, баталсны дараа л дахин бодогдоно.

**Санхүү** — нэхэмжлэл цикл бүрд автоматаар, алданги амьд, төлбөр (бэлэн/данс/бартер)
хамгийн хуучин нэхэмжлэлээс эхэлж хуваарилагдана, илүү төлсөн нь кредит болж
дараагийнхад автоматаар суусна.

**Бартер** — бартер төлбөр бүртгэмэгц хөрөнгө автоматаар үүснэ; зарахад
*орж ирсэн ↔ зарсан үнийн зөрүү* = хэрэгжсэн ашиг/алдагдал тайланд тусна.

**Бусад модуль** — Агуулах (зэрэглэл бүрээр, тооллого), Механизм (Автокраны өдрийн
ажил, зарлага, ашиг), Зээл/Өглөг (хүү/үндсэн, төлөлтийн огноо), Цалин (15/15, НДШ),
Тайлан (P&L + мөнгөн урсгал + Excel), Харилцагчийн бүрэн профайл.

**Хаана ч засаж болно** — тасархай доогуур зураастай тоо, текст бүр дээр дарж
шууд засна (тариф, алданги, барьцаа, хүү, утас…). ✓ дарсны дараа **баталгаажуулах**
асуулт гарна, тэгж байж хадгалагдана.

## 3. Дата, нөөцлөлт (ЧУХАЛ)

Бүх дата **нэг файлд**: `system\backend\jiguur.db`

- Сервер асах бүрд `backend\backups\` дотор автоматаар хуулна (сүүлийн 14-ийг хадгална)
- **Гараар нөөцлөх:** `system\backup.bat` давхар дарна
- 📌 **7 хоногт нэг удаа** `backups\` доторх сүүлийн файлыг USB эсвэл Google Drive
  рүү хуулж байхыг зөвлөж байна. Компьютер эвдэрвэл энэ файлаас бүгдийг сэргээнэ.
- Сэргээх: тэр `.db` файлыг `backend\jiguur.db` болгож хуулаад run.bat

Хавсаргасан файлууд (гэрээний скан г.м.): `system\backend\uploads\`

## 4. Бодит дата руу шилжих (нэг удаа хийгдсэн)

```
system\migrate.bat
```

DB-г цэвэрлэж Numbers файлуудаас бэлдсэн датаг ачаална: **39 харилцагч**
(авлага 2.0 тэрбум₮), **8 идэвхтэй гэрээ** (~5.7 сая₮/өдөр), **нөөц 63,695ш**,
**10 зээл 8.72 тэрбум₮**, **25 бартер хөрөнгө**.

Хуучин авлага «Хуучин үлдэгдэл» гэсэн тусдаа шүүлтүүрт орсон — алдангигүй,
төлбөр бүртгэмэгц хаагдана, тайлангийн орлогод тооцогдохгүй.

## 6. Хөгжүүлэгчид

```
cd system\backend
python -m pytest tests\ -v          # 60 тест
python -m uvicorn app.main:app --reload --port 8000

cd system\frontend
npm install && npm run dev          # localhost:5173, /api → 8000 руу proxy
npm test                            # vitest (4 тест)
npm run build                       # dist руу — backend үүнийг serve хийнэ
```

TDD журам: **TESTING.md**. Neon Postgres руу шилжих:
`set DATABASE_URL=postgresql://...` (schema автоматаар үүснэ).

Бүтэц: `backend/app/services/billing.py` — тооцооны хөдөлгүүр (цикл, пропорц,
алданги, хуваарилалт) · `reports.py` — P&L · `migration.py` — дата шилжүүлэлт.

**Үлдсэн санаанууд (хүсвэл):** И-баримт, QPay, олон компанийн дэмжлэг, мобайл апп.
