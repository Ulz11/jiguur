# Бодит дата руу шилжих журам (P0-10)

Демо датанаас **Отгоо эгчийн бодит дата** руу шилжих алхмууд. Энэ бол мөнгөний
үйл явдал: буруу гүйцэтгэвэл авлагын түүх алдагдана. Тиймээс **бүх ажил
туршилтын санд** хийгдэж, **түүний гарын үсэг**-ээр л ажлын сан солигдоно.

**Алтан дүрэм:** `system/backend/jiguur.db` (ажлын сан) руу шилжүүлэлт
ХЭЗЭЭ Ч шууд гүйцэтгэхгүй. Шилжүүлэлт `jiguur-real.db` дээр л явна, солилт нь
эцсийн алхам.

---

## Урьдчилсан нөхцөл

| Юу | Хаана |
|---|---|
| Гурван .xlsx ажлын дэвтэр | `~/Downloads/Түрээсийн тооцоо 2026 2/` |
| Python орчин | `system/backend/.venv` (`openpyxl` суусан байх) |
| Ажиллах хавтас | `system/backend` |

Windows дээр `.venv\Scripts\python.exe`, macOS/Linux дээр `.venv/bin/python`.
Доор `PY` гэж товчилов.

---

## а) Ажлын санг НӨӨЦЛӨХ

```bash
cd system/backend
cp jiguur.db "backups/jiguur-$(date +%Y%m%d-%H%M%S)-migration.db"
sqlite3 -readonly jiguur.db "SELECT COUNT(*) FROM clients;"   # тоог тэмдэглэ
```

Нөөцлөлгүйгээр цааш явахгүй. Хуулбарын хэмжээ эх файлтай тэнцүү эсэхийг хар.

## б) `real_data.json` угсрах

```bash
PY migration/build_real_data_xlsx.py \
    --src "$HOME/Downloads/Түрээсийн тооцоо 2026 2" \
    --as-of 2026-09-01
```

* Гаралт: `migration/real_data.json` (**git-д ОРОХГҮЙ** — бодит нэр, үлдэгдэл).
* Дэлгэц дээр гарах `⚠` мөр бүрийг уншина. Детерминистик — дахин
  ажиллуулбал ижил файл гарна.
* `--as-of` нь **системийн тоолуур эхлэх өдөр**. Түүний дэвтрийн сүүлийн
  бичилтээс хойш байх ёстой; өмнөх бүх тооцоо эхний үлдэгдэлд аль хэдийн орсон.

## в) ТУРШИЛТЫН сан руу ачаалах

```bash
rm -f jiguur-real.db jiguur-real.db-wal jiguur-real.db-shm
DATABASE_URL="sqlite:///$(pwd)/jiguur-real.db" JIGUUR_NO_CRON=1 \
    PY -m app.migrate --fresh
```

`--fresh` нь **зөвхөн `DATABASE_URL`-д заасан сан**-г цэвэрлэнэ. `DATABASE_URL`
өгөхөө мартвал ажлын сан устана — тиймээс энэ мөрийг бүтнээр нь хуулж ажиллуул.

Windows (cmd):

```bat
set DATABASE_URL=sqlite:///%CD%\jiguur-real.db
set JIGUUR_NO_CRON=1
.venv\Scripts\python.exe -m app.migrate --fresh
```

## г) Тулгалтын тайлан гаргах

```bash
PY migration/reconcile.py
```

Гаралт: `docs/Тулгалтын тайлан.md` (**git-д ОРОХГҮЙ**). Тайлан агуулах нь:

1. нэг харцаар — харилцагч/гэрээ/нэхэмжлэлийн тоо, нийт авлага;
2. **харилцагч бүрээр ₮ тулгалт** — түүний `Үлдэгдэл` ↔ системийн тоо ↔ зөрүү;
3. хийсэн нэрийн нэгтгэлүүд + **нэгтгээгүй** эргэлзээтэй хосууд;
4. нэг дэвтэрт бий, нөгөөд нь алга харилцагчид;
5. идэвхтэй гэрээ — хуудас vs паркийн дэвтрийн тооны зөрүү;
6. каталогт байхгүй материал;
7. задлагдаагүй нүд + бүх анхааруулга;
8. **«Тооцоо нийлсэн:» гарын үсгийн блок**.

Туршилтын санг нүдээрээ шалгах бол:

```bash
DATABASE_URL="sqlite:///$(pwd)/jiguur-real.db" PY -m uvicorn app.main:app --port 8001
```

(ажлын серверийг **зогсоохгүй** — өөр порт дээр гаргана)

## д) ГАРЫН ҮСЭГ

Тайланг хэвлэж Отгоо эгчид өгнө. Тэр:

* харилцагч бүрийн `Үлдэгдэл`, `Барьцаа`-г хараад зөвшөөрнө;
* §2.1-ийн **зөрүүтэй** харилцагч бүрийн хувьд аль тоо үнэн болохыг заана;
* §3.1-ийн **нэгтгээгүй** нэрсийн талаар шийдвэр гаргана;
* §5-ийн хуудас↔парк зөрүүг батална;
* §6-гийн каталогийн нүхийг нээх эсэхийг хэлнэ.

Түүний засвар бүрийг `build_real_data_xlsx.py`-ийн `ALIASES` / `AMBIGUOUS`
хүснэгтэд буулгаж, **б → г алхмуудыг дахин гүйцэтгээд** шинэ тайлан гаргана.
Тайлан 100% таарч, гарын үсэг зурагдтал цааш явахгүй.

## е) СОЛИЛТ (гарын үсэг зурагдсаны дараа)

```bash
cd system/backend
# 1. серверээ зогсоо (run.bat цонхыг хаа)
# 2. сүүлчийн нөөцлөлт
cp jiguur.db "backups/jiguur-$(date +%Y%m%d-%H%M%S)-pre-cutover.db"
# 3. солих
mv jiguur.db jiguur-demo.db
mv jiguur-real.db jiguur.db
rm -f jiguur.db-wal jiguur.db-shm
# 4. серверээ асаа (run.bat) — otgoo / 1234
```

Шалгах: Дашбоардын «Нийт үлдэгдэл» нь тайлангийн §1-ийн дүнтэй тэнцүү байх ёстой.

## ё) БУЦААХ (rollback)

Ямар нэг зүйл болохгүй бол:

```bash
cd system/backend
# серверээ зогсоо
mv jiguur.db jiguur-real-failed.db
cp "backups/jiguur-<огноо>-pre-cutover.db" jiguur.db
rm -f jiguur.db-wal jiguur.db-shm
# серверээ асаа
```

Нөөцлөлтүүд `system/backend/backups/` дотор, 14 хоногоор эргэлддэг
(`app/backup.py`). Солилтын өмнөх нөөцлөлтийг **гараар** тусад нь хадгалах нь
зөв — эргэлтэд орж алга болохоос сэргийлнэ.

## Юуг АНХААРАХ

* **`--fresh` нь устгадаг.** `DATABASE_URL` заалгүй ажиллуулбал ажлын сан
  цэвэрлэгдэнэ. Үргэлж бүтэн мөрөөр нь хуул.
* **Алданги 0.** Шилжүүлсэн гэрээ бүр `penalty_percent=0`-той төрнө — тэр
  амьдралдаа алданги нэхээгүй, систем түүний нэрийн өмнөөс нэхэхгүй
  (`tests/test_migration.py::test_migrated_contracts_never_arm_penalty`).
* **Барьцаа балансын ГАДНА.** Сөрөг үлдэгдэлтэй харилцагчийн барьцаа ч
  хадгалагдана (`test_credit_client_keeps_her_deposit`).
* **Бодит дата git-д орохгүй.** `.gitignore`-д: `real_data.json`,
  `jiguur-real.db*`, `docs/Тулгалтын тайлан.md`. Хэрэгслүүд нь орно, дата нь
  ХЭЗЭЭ Ч орохгүй.
* **Бартерын жагсаалт гараар баталгаажсан** (`migration/barter_manual.py`) —
  «Бартер болон авлага-26» ба «Бартерт тооцуулах -26» хуудсууд нэгдсэн
  бүтэцгүй тул автомат задлагдаагүй. Хөрөнгө нэмэгдвэл тэр файлыг засна.
* **Эхний улирал хоёр системийг зэрэг хөтөлнө** (docs/Чадварын харьцуулалт.md
  §4). Excel нь баримт баримтаараа тэтгэвэрт гарна.
