# UI зарчим — Жигүүр Зам

Энэ бол **гэрээ**: шинэ хуудас, шинэ панел нэмэх бүрд эдгээр дүрмийг дагана.
Дагахгүй бол систем дахин «тарж», Отгоо эгч хаана байгаагаа алдана.

## 0. Гол зүйрлэл — НЭГ дэвтэр

Отгоо Numbers дээр **нэг дэвтэр**, дотор нь олон хуудастай ажилладаг байсан.
Хуудсууд нь бие биенээ иш татна, нэр дээр нь дарж нөгөө хуудас руу үсэрнэ.
Систем ЯГ ийм байх ёстой: 19 тусдаа програм биш, **19 хуудастай нэг дэвтэр**.

Тархай мэдрэмж гурван зүйлээс төрдөг:
мухардмал нэр (дарагдахгүй), тэнэсэн хуудас (эхлэл нь өөр өөр),
хувирдаг үг (нэг зүйл хуудас болгонд өөр нэртэй). Доорх 1–3 нь энэ гурвыг хаана.

## 1. Холбоосын дүрэм

**Объект бүр НЭГ хуудастай, түүнийг нэрлэсэн газар бүрээс тэр хуудас руу очно.**

| Объект | Канон хуудас |
|---|---|
| Харилцагч | `/clients/:id` |
| Гэрээ | `/contracts/:id` |
| Материал | `/warehouse/materials/:id` |
| Механизм | `/machines` |

Хаягийг гараар угсрахгүй — `src/lib/links.ts`-ээс авна
(`clientHref`, `contractHref`, `materialHref`, `contractsHref`, `auditHref`,
`notificationHref`). Тэнд байхгүй зам бол шинэ зам биш, алдаа.

Хэлбэр:
- **Мөр бүхэлдээ** өөрийн ГОЛ объект руу — `rowClickProps(...)` (гар, Enter/Space,
  дуудагдах нэр гурав дагалдана). Хулгана хүрэхэд бүдэг `→` тайван зогсоно.
- **Мөрөн дэх ӨӨР объектын нэр** нь өөрийн хуудас руу — жирийн `<Link>`,
  `hover:underline`-тай, багана нь `onClick={e => e.stopPropagation()}` (мөрийн
  товшилтыг булаахгүй).
- **Мөрийн гарчиг болж байгаа нэр** ХОЛБООС БОЛОХГҮЙ (ж: Гэрээнүүд дэх
  харилцагчийн нэр) — тэр товшилт мөрийнхөө очих газар руу л явна.
- **Худал холбоос үүсгэхгүй.** Хуудасгүй объект (төлбөр, хөдөлгөөн, нэхэмжлэл,
  зээл, ажилтан, бартер хөрөнгө) текст хэвээр. `auditHref` яг үүнийг хамгаална.
- **Хаалттай хуудас руу холбоос үүсгэхгүй.** Үйлдвэрийн даргад Зээл, Авлага
  цуглуулах, Цалин, Тайлан, Аналитик, Бүртгэл, Тохиргоо БАЙХГҮЙ — түүнд тэр мөр
  зүгээр л уншигдана (`notificationHref` рольтойгоо шалгана).
- Жагсаалтын **шүүлтүүр хаягаар дамжина**: `/contracts?state=ending`.

## 2. Хуудасны анатоми

Дээрээс доош, ҮРГЭЛЖ ижил дараалал:

```
kicker (жижиг том үсэг: ХУУДАС • гол тоо)
H1 (.dashboard-title)         [гол үйлдэл — БАРУУН]
дэд мөр (.dashboard-subtitle)
шүүлтүүр / хайлт
агуулга (KPI → хүснэгт/панел)
```

```jsx
<div className="dashboard-header">
  <div>
    <div className="dashboard-kicker">АГУУЛАХ <span>•</span> 20 МАТЕРИАЛ</div>
    <h1 className="dashboard-title">Агуулах</h1>
    <p className="dashboard-subtitle">…</p>
  </div>
  <button className="btn-primary command-action">+ Нэмэх</button>
</div>
```

- Хуудсанд **нэг л `<h1>`**, `<div>`-ээр гарчиг зурахгүй.
- Гол үйлдэл БАРУУН дээд булан, `command-action`-той. Хоёр товч байвал
  хоёрдогч нь `btn-secondary`, зүүн талд нь.
- **Дэлгэрэнгүй хуудас** (гэрээ, харилцагч, материал) өөр эхэлнэ:
  `← <хаана> руу буцах` (`btn-ghost mb-3 inline-flex`) → `h1 text-[22px]` +
  төлвийн pill-үүд → мета мөр (InlineEdit-үүд) → үйлдлүүд баруун талд.
- Дэлгэрэнгүй хуудсууд бие биенээ **хоёр талаас** нээнэ:
  гэрээ ⇄ харилцагч ⇄ материал.

## 3. Толь бичиг (нэг ойлголт — нэг үг)

| Ойлголт | Хэрэглэх үг | Хэрэглэхгүй |
|---|---|---|
| Харилцагч дээр байгаа, буцаж ирээгүй материал | **Түрээсэнд** | ~~Гадаа~~ |
| Тооцооны баримт | **Нэхэмжлэл** | ~~Нэхэмжлэх~~ |
| Авлага нэхэх хуудас | **Авлага цуглуулах** | ~~Авлага цуглуулалт~~ |
| Нүүр хуудас | **Удирдлагын төв** | ~~Дашбоард~~ |
| Хөдөлгөөний жагсаалт | **Хөдөлгөөний түүх** | ~~Сүүлийн хөдөлгөөн~~ |

**Санаатай ЯЛГААТАЙ үлдсэн (нэгтгэж БОЛОХГҮЙ):**

- **Төлбөр** = харилцагчаас орж ирсэн мөнгө · **Төлөлт** = зээлээр гарсан мөнгө.
- **Авлага** = харилцагчийн өр · **Үлдэгдэл** = үлдсэн дүн/тоо (нөөц ч гэсэн).
  Харилцагчийн түвшний тоог «**Авлагын үлдэгдэл**» гэж бүтнээр нь нэрлэнэ.
- **Хугацаа хэтэрсэн** = гарчиг, KPI дээр бүтэн нэр ·
  **Хэтэрсэн** = pill, шүүлтүүр, баганын толгой дээрх богино хэлбэр.
- Товчны нэр **үйл үгээр** эхэлнэ: «Төлбөр бүртгэх», «Тооллого хийх», «Зарах».

Хуудсын нэр гурван газар ижил байна: **цэс = `lib/titles.ts` = `<h1>`**.

## 4. Харилцах конвенцууд (аль хэдийн байгаа — хэвээр нь дага)

- **Дарж засах — 2 алхам.** `InlineEdit`: утга → ✓ → «…солих уу?». `label`
  заавал өг (уншигч «330 · засах» гэж дуудвал юуг засахыг мэдэхгүй).
- **Мөнгө хөдөлгөх, устгах — `ConfirmModal`.** Болох гэж буйгаа navy `Receipt`
  дээр ЭХЛЭЭД харуулаад л асууна; аюултай үйлдэлд фокус «Болих» дээр очно.
- **Талбартай модал = `FormModal`** (`dirty` нь ЗААВАЛ). Санамсаргүй гадна
  товшилт, Escape бөглөсөн зүйлийг чимээгүй устгахгүй.
- **Сервер рүү явуулдаг товч** = `SubmitButton` (өөрийгөө түгжинэ — нэг төлбөр
  хоёр удаа бүртгэгдэхгүй).
- **Хүснэгт нь Excel** — `.th`/`.td` бүтэн хүрээтэй (`border-collapse`),
  тоо `tabular-nums`, мөнгө баруун тийш. Жагсаалтад дугуйлсан («12.3 сая»),
  ганц баримт дээр бүтэн төгрөг; дугуйлсан тоо `title`-даа бүтнээ авч явна.
- **Хоосон төлөв** = `<Empty>`, шүүлтүүрээс болж хоосорсон бол ГАРАХ товчтой.
- **Дахин татах** = `<Refreshing>` (тоо байрандаа үлдэж бүдгэрнэ, хоосорохгүй).
- **Хүрэх талбай**: `--target-lg 52px` (хуруу, планшет) ·
  `--target 44px` (энгийн товч, `.inp`) · `--target-sm 36px` (хүснэгтийн
  нягт үйлдэл, `.btn-row`). 36px-ээс намхан дарагддаг юм БАЙХГҮЙ.
- **Фокусын бөгж**: цайвар гадаргуу дээр navy (`--ring`), navy sidebar дээр
  улбар (`--ring-navy`). `:focus-visible` — хулганаар дарахад гарахгүй.

### Өнгөний утга

Өнгө нь **ШАТ (scale) дотроо** утгатай, систем даяар нэг утгатай биш. Шат бүр
өөрийн үгтэй тул хажуу хажууд нь тааралдсан ч ойлголт зөрөхгүй.

**Төлөв ба сануулга** (хаана ч ижил):

| Утга | Токен |
|---|---|
| Эерэг, орсон мөнгө, хэвийн | `--color-money` `#17755a` |
| Анхаар: дуусах дөхсөн, буцаалт, засвар, амлалт | `--color-warn` `#a2530a` |
| Хэтэрсэн, акт, устгах | `--color-danger` `#b3272d` |
| Брэнд: идэвхтэй, түрээс, гол үйлдэл | `--color-brand` `#f88712` (бичиг: `--color-brand-ink`) |

**Гэрээний төрөл** (`TypePill`): Түрээс → брэнд · Худалдаа → `--color-violet`.
**Төлбөрийн хэлбэр** (pill, гурван дэлгэц дээр ижил):
Бэлэн → ногоон · Данс → брэнд · **Бартер → `--color-violet` `#6756a4`**.
**Графикийн цуваа**: Түрээс → брэнд улбар · Худалдаа → navy `#253886` ·
Бартер → violet · Гарсан мөнгө → улаан.

⚠ Хоёр анхааруулга:
- `.pill-blue` нь ЦЭНХЭР биш — брэндийн улбар зурдаг
  (`bg-brand-50 text-brand-ink`). Нэр нь түүхэн; өнгө нь дээрх шатаар явна.
- Violet нь ХОЁР шат дээр өөр утгатай (гэрээний төрөл «худалдаа» ·
  төлбөрийн хэлбэр «бартер»). Тиймээс дараах дүрэм онцгойлон чухал.

**Өнгө дангаараа утга зөөхгүй.** Улаан/улбар/ногоон ялгаа дэргэдээ ҮГТЭЙ явна
(«хэтэрсэн», «дуусах дөхсөн», «бага/дунд/хэвийн») — хэвлэсэн цаас, өнгө
ялгадаггүй нүд хоёуланд нь мэдээлэл үлдэнэ.

## 5. Шинэ зүйл нэмэхийн өмнө

1. Энэ объект хуудастай юу? Тэгвэл нэрлэсэн газар бүрээсээ тийш **холбогдсон** уу?
2. Хуудас **§2-ын анатомитой** таарч байна уу (kicker → H1 → үйлдэл → шүүлтүүр)?
3. Хэрэглэсэн үг чинь **§3-ын толинд** байна уу? Байхгүй бол ижил утгатай үг
   аль хэдийн байж магадгүй — эхлээд хай, дараа нь нэм.
4. Дарагддаг бүхэн **гараар** дарагдаж байна уу (Tab → Enter)?
5. Мөнгө хөдөлгөж байна уу? Тэгвэл **Receipt + ConfirmModal**.
